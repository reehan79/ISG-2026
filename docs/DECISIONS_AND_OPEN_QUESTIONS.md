**Updated:** 2026-09-12

This file prevents uncertain statements from silently turning into programme facts.

---

## A. Consolidated decisions

1. **IST/SSTRL/NCGSA remains the Pakistan national hub / organizer interface.**
2. **Distributed Pakistan Ground-Lab nodes are part of the architecture.**
3. Operational October node count is intentionally small; quality/capability beats logos.
4. **MARS-LINK v2 is the primary Model Experiment.**
5. MARTA/AI is **not** a separate Model Experiment.
6. Mode C for the formal experiment is a **deterministic priority-aware procedure aid**, not an unvalidated ML controller.
7. Fixed A->B->C execution on identical scenarios is rejected.
8. Measured episodes use standardized Earth-message content/timing.
9. University/SUPARCO node inputs do not alter measured episodes.
10. HIL/KidSat/TwinLink is optional, local and non-critical for October.
11. KidSat is described as a representative cyber-physical asset, never Mars hardware.
12. October and the later MissionLab Challenge reuse the same experiment/scenario/evidence infrastructure.
13. CubeSTEM is the technology/platform contributor; the scientific experiment is not written as a CubeSTEM product test.
14. The ISG-2026 repository is programme authority only; it does not fork Digital Twin/TwinLink physics/physical authority.
